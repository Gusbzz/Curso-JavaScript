# Curso JavaScript 📚

Repositório dedicado aos meus estudos em **JavaScript** — fundamentos, estruturas de dados e práticas modernas da linguagem.

> 🎯 Objetivo: consolidar bases sólidas em JS para evoluir para DOM, assincronismo, APIs e frameworks modernos.

## 🚀 Tecnologias

- JavaScript (ES6+)
- HTML5 para testes no navegador
- Node.js (para execução via terminal)

## 📁 Estrutura

```
Javascript/
├── index.html          # Base HTML para testes no navegador
├── main.js             # Arquivo principal de testes
├── string.js           # Manipulação de strings
├── arrays.js           # Fundamentos de arrays
├── arrays_method.js    # Métodos de arrays (map, filter, reduce)
├── objects.js          # Objetos e destructuring
└── json.js             # JSON.stringify / JSON.parse
```

## 📖 Conteúdo Estudado

- [x] Variáveis e Tipos
- [x] Strings - concatenação, template literals, `split`, `toUpperCase`
- [x] Arrays - `push`, `unshift`, `pop`, `indexOf`, `sort`, `Array.isArray`
- [x] Métodos de Array - `map`, `filter`, `reduce`
- [x] Objetos - criação, objetos aninhados, destructuring
- [x] JSON - serialização e desserialização
- [ ] Condicionais e Loops
- [ ] Funções e Arrow Functions

- [ ] Assincronismo (Promises, async/await)
- [ ] Fetch API

## ▶️ Como Executar

### No navegador
1. Abra `index.html` no navegador
2. Abra o DevTools (F12) > Console para ver os outputs
3. Altere o `<script src="main.js">` para testar outros arquivos (ex: `arrays.js`)

### No Node.js
```bash
node arrays.js
node objects.js
node string.js
node json.js
node arrays_method.js
```
